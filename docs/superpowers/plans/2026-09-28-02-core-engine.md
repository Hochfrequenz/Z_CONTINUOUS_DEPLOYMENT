# Core engine - implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended)
> or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`)
> syntax for tracking.

**Goal:** build every rule of the continuous-deployment spec that is pure logic, plus the
orchestrator, so that the whole flow of spec section 2 is unit-tested against fakes before any
abapGit code exists.

**Architecture:** seven small global classes and ten interfaces, all in package
`Z_CONTINUOUS_DEPLOYMENT`. Pure functions decide (`ZCL_CDEPLOY_DECISION`), change state
(`ZCL_CDEPLOY_STATE_RULES`), judge (`ZCL_CDEPLOY_CHECKS`, `ZCL_CDEPLOY_ALERT_RULES`,
`ZCL_CDEPLOY_STATUS_LIGHT`) and parse (`ZCL_CDEPLOY_VERSION`). `ZCL_CDEPLOY_RUN` only sequences them
and talks to the outside through injected interfaces.

**Tech stack:** ABAP 7.40 SP08 syntax floor, ABAP Unit (local test classes in the class's test
include), abaplint 2.120.60 in CI. Nothing here touches abapGit, the database, the network or the
clock.

**Spec:** `docs/superpowers/specs/2026-09-28-continuous-deployment-design.md`. **Overview and workflow:** `00-overview.md` (read section 3 first).

**Executed by nobody yet.** The code below parses and type-checks under this repository's
`abaplint.json`; it has not run. Expect the first real run to find defects; that is what the red/green
steps are for. When a test and the code disagree, read the spec, decide which is wrong, and fix that
one.

### Task 2: `ZCL_CDEPLOY_VERSION` - parse and order tags

Spec 2.1. One fixed grammar, semantic-versioning precedence, no per-repository pattern.

**Files:** `work/zcl_cdeploy_version.clas.abap`, `work/zcl_cdeploy_version.clas.testclasses.abap`.

- [ ] **Step 1: Save the tests** to `work/zcl_cdeploy_version.clas.testclasses.abap`.

```abap
CLASS ltc_version DEFINITION FINAL FOR TESTING RISK LEVEL HARMLESS DURATION SHORT.

  PRIVATE SECTION.
    METHODS eligible_tags       FOR TESTING.
    METHODS skipped_tags        FOR TESTING.
    METHODS numeric_ordering    FOR TESTING.
    METHODS suffix_ordering     FOR TESTING.
    METHODS newest_of_several   FOR TESTING.
    METHODS newest_of_none      FOR TESTING.

    METHODS assert_eligible
      IMPORTING iv_name TYPE string.
    METHODS assert_skipped
      IMPORTING iv_name   TYPE string
                iv_reason TYPE string.
    METHODS assert_newer
      IMPORTING iv_newer TYPE string
                iv_older TYPE string.
    METHODS version
      IMPORTING iv_name           TYPE string
      RETURNING VALUE(rs_version) TYPE zif_cdeploy_types=>ty_version.
ENDCLASS.


CLASS ltc_version IMPLEMENTATION.

  METHOD version.
    DATA(ls_result) = zcl_cdeploy_version=>parse( iv_name ).
    cl_abap_unit_assert=>assert_equals( act = ls_result-ok exp = abap_true msg = |{ iv_name } must parse| ).
    rs_version = ls_result-version.
  ENDMETHOD.

  METHOD assert_eligible.
    cl_abap_unit_assert=>assert_equals(
      act = zcl_cdeploy_version=>parse( iv_name )-ok
      exp = abap_true
      msg = |{ iv_name } must be eligible| ).
  ENDMETHOD.

  METHOD assert_skipped.
    DATA(ls_result) = zcl_cdeploy_version=>parse( iv_name ).
    cl_abap_unit_assert=>assert_equals( act = ls_result-ok exp = abap_false msg = |{ iv_name } must be skipped| ).
    cl_abap_unit_assert=>assert_equals( act = ls_result-reason exp = iv_reason msg = |reason for { iv_name }| ).
  ENDMETHOD.

  METHOD assert_newer.
    cl_abap_unit_assert=>assert_equals(
      act = zcl_cdeploy_version=>compare( is_a = version( iv_newer ) is_b = version( iv_older ) )
      exp = 1
      msg = |{ iv_newer } must be newer than { iv_older }| ).
    cl_abap_unit_assert=>assert_equals(
      act = zcl_cdeploy_version=>compare( is_a = version( iv_older ) is_b = version( iv_newer ) )
      exp = -1
      msg = |{ iv_older } must be older than { iv_newer }| ).
  ENDMETHOD.

  METHOD eligible_tags.
    assert_eligible( `v1.2.3` ).
    assert_eligible( `v0.0.0` ).
    assert_eligible( `v1.2.3-rc1` ).
    assert_eligible( `v1.2.3-anything` ).
    assert_eligible( `v1.2.3-rc.10` ).
    assert_eligible( `v1.2.3-x-y` ).

    DATA(ls_parsed) = zcl_cdeploy_version=>parse( iv_name = `v10.20.30-rc.1` iv_commit = `abc123` ).
    cl_abap_unit_assert=>assert_equals( act = ls_parsed-version-major  exp = 10 ).
    cl_abap_unit_assert=>assert_equals( act = ls_parsed-version-minor  exp = 20 ).
    cl_abap_unit_assert=>assert_equals( act = ls_parsed-version-patch  exp = 30 ).
    cl_abap_unit_assert=>assert_equals( act = ls_parsed-version-suffix exp = `rc.1` ).
    cl_abap_unit_assert=>assert_equals( act = ls_parsed-version-commit exp = `abc123` ).
  ENDMETHOD.

  METHOD skipped_tags.
    " not a version tag at all
    assert_skipped( iv_name = `1.2.3`                    iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `V1.2.3`                   iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `v1.2`                     iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `v1.2.3.4`                 iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `v1.2.3rc1`                iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `v1.2.3-`                  iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `v01.2.3`                  iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `release-1.2.0`            iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    assert_skipped( iv_name = `my-customer-final17-2026` iv_reason = zcl_cdeploy_version=>c_reason-no_match ).
    " a component that does not fit an ABAP i
    assert_skipped( iv_name = `v2147483648.0.0`          iv_reason = zcl_cdeploy_version=>c_reason-too_large ).
    assert_skipped( iv_name = `v1.99999999999.0`         iv_reason = zcl_cdeploy_version=>c_reason-too_large ).
    " a suffix with an empty identifier or a numeric identifier with a leading zero
    assert_skipped( iv_name = `v1.2.3-rc..1`             iv_reason = zcl_cdeploy_version=>c_reason-bad_suffix ).
    assert_skipped( iv_name = `v1.2.3-rc.01`             iv_reason = zcl_cdeploy_version=>c_reason-bad_suffix ).
    assert_skipped( iv_name = `v1.2.3-.rc`               iv_reason = zcl_cdeploy_version=>c_reason-bad_suffix ).
    " the largest component that fits is eligible
    assert_eligible( `v2147483647.0.0` ).
  ENDMETHOD.

  METHOD numeric_ordering.
    assert_newer( iv_newer = `v1.10.0` iv_older = `v1.9.0` ).
    assert_newer( iv_newer = `v2.0.0`  iv_older = `v1.99.99` ).
    assert_newer( iv_newer = `v1.2.4`  iv_older = `v1.2.3` ).
    cl_abap_unit_assert=>assert_equals(
      act = zcl_cdeploy_version=>compare( is_a = version( `v1.2.3` ) is_b = version( `v1.2.3` ) )
      exp = 0 ).
  ENDMETHOD.

  METHOD suffix_ordering.
    " a tag without a suffix is newer than the same version with one
    assert_newer( iv_newer = `v1.2.0`        iv_older = `v1.2.0-rc1` ).
    " numeric identifiers compare as numbers when separated by dots ...
    assert_newer( iv_newer = `v1.2.0-rc.10`  iv_older = `v1.2.0-rc.2` ).
```

```abap
  METHOD parse.

          lv_minor  TYPE string,
          lv_patch  TYPE string,
          lv_group  TYPE string,
          lv_suffix TYPE string,
          lv_large  TYPE abap_bool.

    rs_result-version-commit = iv_commit.

    FIND REGEX '^v(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)(-(.+))?$' IN iv_name
         SUBMATCHES lv_major lv_minor lv_patch lv_group lv_suffix.
    IF sy-subrc <> 0.
      rs_result-reason = c_reason-no_match.
      RETURN.
    ENDIF.

    to_component( EXPORTING iv_text = lv_major IMPORTING ev_value = rs_result-version-major ev_too_large = lv_large ).
    IF lv_large = abap_true.
      rs_result-reason = c_reason-too_large.
      RETURN.
    ENDIF.

    IF lv_large = abap_true.
      rs_result-reason = c_reason-too_large.
      RETURN.
    ENDIF.
    to_component( EXPORTING iv_text = lv_patch IMPORTING ev_value = rs_result-version-patch ev_too_large = lv_large ).
    IF lv_large = abap_true.
      rs_result-reason = c_reason-too_large.

      rs_result-reason = c_reason-bad_suffix.
      RETURN.
    ENDIF.

    rs_result-version-suffix = lv_suffix.

  ENDMETHOD.

    DATA lv_packed TYPE p LENGTH 16.
    ev_too_large = abap_false.
    IF strlen( iv_text ) > 10.
      ev_too_large = abap_true.
      RETURN.
    ENDIF.
    lv_packed = iv_text.
    IF lv_packed > 2147483647.
      ev_too_large = abap_true.
      RETURN.
    ENDIF.
    ev_value = lv_packed.
  ENDMETHOD.


  METHOD suffix_valid.
    DATA lt_ids TYPE string_table.
    rv_valid = abap_false.
    SPLIT iv_suffix AT '.' INTO TABLE lt_ids.
    LOOP AT lt_ids INTO DATA(lv_id).
      IF lv_id IS INITIAL.
        RETURN.
      ENDIF.
      IF is_numeric( lv_id ) = abap_true AND strlen( lv_id ) > 1 AND lv_id(1) = '0'.

  METHOD is_numeric.
    rv_numeric = xsdbool( iv_text CO '0123456789' ).
  ENDMETHOD.


  METHOD compare.
    IF is_a-major <> is_b-major.
      rv_result = COND #( WHEN is_a-major > is_b-major THEN 1 ELSE -1 ).
      RETURN.
    ENDIF.
    IF is_a-minor <> is_b-minor.
      rv_result = COND #( WHEN is_a-minor > is_b-minor THEN 1 ELSE -1 ).
      RETURN.
    ENDIF.
    IF is_a-patch <> is_b-patch.
      rv_result = COND #( WHEN is_a-patch > is_b-patch THEN 1 ELSE -1 ).
      RETURN.
    ENDIF.
    rv_result = compare_suffix( iv_a = is_a-suffix iv_b = is_b-suffix ).
  ENDMETHOD.


  METHOD compare_suffix.
    DATA: lt_a TYPE string_table,
          lt_b TYPE string_table.

    " no suffix is newer than any suffix (v1.2.0 > v1.2.0-rc1)
    IF iv_a IS INITIAL AND iv_b IS INITIAL.
      rv_result = 0.
      RETURN.
    ENDIF.
    IF iv_a IS INITIAL.
      rv_result = 1.
      RETURN.
    ENDIF.
    IF iv_b IS INITIAL.
      rv_result = -1.
      RETURN.
    ENDIF.

    SPLIT iv_a AT '.' INTO TABLE lt_a.
    SPLIT iv_b AT '.' INTO TABLE lt_b.

    DATA(lv_common) = nmin( val1 = lines( lt_a ) val2 = lines( lt_b ) ).
    DO lv_common TIMES.
      DATA(lv_cmp) = compare_identifier( iv_a = lt_a[ sy-index ] iv_b = lt_b[ sy-index ] ).
      IF lv_cmp <> 0.
        rv_result = lv_cmp.
        RETURN.
      ENDIF.
    ENDDO.

    " all common identifiers equal: the shorter list is older
    IF lines( lt_a ) > lines( lt_b ).
      rv_result = 1.
    ELSEIF lines( lt_a ) < lines( lt_b ).
      rv_result = -1.
    ELSE.
      rv_result = 0.
    ENDIF.
  ENDMETHOD.


  METHOD compare_identifier.
    DATA(lv_a_num) = is_numeric( iv_a ).
    DATA(lv_b_num) = is_numeric( iv_b ).

    IF lv_a_num = abap_true AND lv_b_num = abap_true.
      " no leading zeros (validated): longer is bigger, then plain string order.
      " Comparing by length first means no overflow can occur.
      IF strlen( iv_a ) <> strlen( iv_b ).
        rv_result = COND #( WHEN strlen( iv_a ) > strlen( iv_b ) THEN 1 ELSE -1 ).
      ELSEIF iv_a > iv_b.
        rv_result = 1.
      ELSEIF iv_a < iv_b.
        rv_result = -1.
      ELSE.
        rv_result = 0.
      ENDIF.
    ELSEIF lv_a_num = abap_true.
      rv_result = -1.                          " numeric is older than alphanumeric
    ELSEIF lv_b_num = abap_true.
      rv_result = 1.
    ELSEIF iv_a > iv_b.
      rv_result = 1.
    ELSEIF iv_a < iv_b.
      rv_result = -1.
    ELSE.
      rv_result = 0.
    ENDIF.
  ENDMETHOD.


  METHOD newest.
    LOOP AT it_versions INTO DATA(ls_version).
      IF rs_version-name IS INITIAL OR compare( is_a = ls_version is_b = rs_version ) > 0.
        rs_version = ls_version.
      ENDIF.
    ENDLOOP.
  ENDMETHOD.

ENDCLASS.
```
